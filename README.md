## 🇨🇳 中文

这是一个针对两家及以上上市公司或股票的横向研究技能。它把大盘与板块、外围市场、供应链、重要新闻与监管、商业模式、经营财务、成长、预期、估值、股价、组合等维度串成一条分析链，并专门处理 A/H 股与跨上市地相对价值。进入分析前会先设置 delivery_mode、初始化比较范围，并加载默认的核心财务金融数据底座。内容准入与写作质量、选择能力、默认组合都有既定规则，避免漏维度或凑结论。最终产出飞书文档、高级金融图表与可复核的多维报告。

### ✨ 能做什么

- 输入两家以上公司或股票 → 输出覆盖估值、成长、财务、股价的多维对比报告
- A/H 股与跨上市地相对价值测算，找出同一资产的定价分歧
- 大盘与板块、外围市场、供应链、重要新闻与监管一并纳入，不只看财报
- 先用 delivery_mode 与比较范围初始化，再进入正式分析
- 默认核心财务金融数据底座，数字可复核、可追溯
- 面向公司比较、选股、财报估值对比、股价与事件复盘、配对交易与组合适配

## 🇬🇧 English

This skill runs cross-sectional research on two or more listed companies or stocks. It works a fixed chain of dimensions—market and sector, overseas markets, supply chain, material news and regulation, business model, operating and financials, growth, expectations, valuation, share price, portfolio—and handles A/H and cross-listing relative value specifically. Before analysis starts it sets delivery_mode, initializes the comparison scope, and loads a default core financial data foundation. Content admission, writing quality, capability selection, and default portfolio rules keep the output from missing dimensions or padding conclusions. Deliverables are a Lark doc, advanced financial charts, and an auditable multi-dimensional report.

### ✨ What it does

- Two or more tickers in, one multi-dimensional comparison out (valuation, growth, financials, price)
- A/H share and cross-listing relative value to spot mispricing of the same asset
- Pulls in market, sector, overseas, supply chain, news, and regulatory context, not just the financials
- Initializes delivery_mode and comparison scope before any analysis runs
- Ships with a default core financial data foundation, so every number is auditable
- Built for company comparison, stock picking, earnings and valuation reviews, event post-mortems, pair trading, portfolio fit
